Paste your Google Form's pre-filled link, then replace the code value with the literal text CODE. Leave blank to just display the raw code for testing.
Bundles the fields above into one URL. Bookmark it and it'll load pre-filled every time — one link per section/course, so nobody has to re-paste or risk mixing up another section's form.
How to set this up in Google Forms
1. Create a form with fields for name, student ID, and a short-answer "Code" field.

2. Open the form, click the ⋮ menu → "Get pre-filled link."

3. Fill in sample name/ID, and type CODE literally into the Code field.

4. Click "Get link," copy it, paste it above — this tool swaps CODE for the live token each refresh.

5. After lecture, filter form responses to codes that appear in the session log on the right to catch late/stale submissions.
